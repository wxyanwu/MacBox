# MacBox 1.1.2（Build 105）

Apple Silicon Mac 搜索修复版，保留既有 Bundle ID、订阅、偏好、观看记录和已签名 Android Bridge APK。

## 更新内容

- 批量搜索时把 Android/DEX 站点返回的空列表视为正常结果，避免对每个空结果执行 Spider 重建、首页加载和二次搜索而占满 Bridge。
- 同一个 Android Bridge 最多同时搜索 8 个站点；批量搜索每站只请求第一页。单站搜索的原有恢复逻辑保留。
- 搜索进度继续按实际可搜索站点统计，线路自身返回错误或超时仍在搜索详情中提示。

## 验证范围

- 使用实际订阅和“兰香如故”检查搜索结果、进度及失败明细。
- 不同第三方站点会随其插件和网络状态变化；本次修复不保证每个站点都返回结果。

本项目为独立维护的 ad-hoc 签名版本，未声明 Apple 公证或上游官方发布。
