# MacBox 1.1.2（Build 105）

Apple Silicon Mac 修复版，保留既有 Bundle ID、订阅、偏好、观看记录和已签名 Android Bridge APK。

## 更新内容

- 批量搜索时把 Android/DEX 站点返回的空列表视为正常结果，避免对每个空结果执行 Spider 重建、首页加载和二次搜索而占满 Bridge。
- 同一个 Android Bridge 最多同时搜索 8 个站点；批量搜索每站只请求第一页。单站搜索的原有恢复逻辑保留。
- 搜索进度继续按实际可搜索站点统计，线路自身返回错误或超时仍在搜索详情中提示。
- 修复长时间休眠后对已关闭播放器继续执行恢复播放的问题；唤醒时核对当前播放请求和播放器实例。
- 改进 Android 模拟器及私有 ADB 服务端口变化后的进程识别，避免误把仍属于本次启动的模拟器视为旧实例。
- 修复部分配置中心卡片无法打开、网盘登录操作等待期间缺少可见进度与取消入口，以及夸克扫码完成后弹窗难以关闭的问题。
- 改进 Android Bridge 的网盘媒体代理；当第三方本地 Kaiser 代理返回 502 时，尝试其原始媒体地址，且不向外部媒体主机转发本地代理凭据。
- 对同一剧集、同一文件提供的两种百度签名线路，在原线路失败后尝试“百度原画(无限)”线路；403 错误不再一律提示重新登录。
- 补强 CoreAudio 热插拔补丁对部分监听器注册失败和音频输出初始化失败的清理。

## 验证范围

- 使用实际订阅和“兰香如故”检查搜索结果、进度及失败明细。
- 安装版实测王小二的百度问题剧集可切换等价线路播放；王小二夸克、摸鱼儿百度和夸克的样本也播出画面。
- 新增针对配置中心、线路匹配、模拟器进程识别和 Bridge 代理的回归检查。Xcode 的 App 测试运行器在本机未能启动；构建成功不代表这些 XCTest 已通过。
- 其他网盘未登录，也未逐一验证所有站点与剧集。第三方站点及网盘线路会随上游状态变化。

本项目为独立维护的 ad-hoc 签名版本，未声明 Apple 公证或上游官方发布。
