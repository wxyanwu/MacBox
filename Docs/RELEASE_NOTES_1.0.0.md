# MacBox 1.0.0（Build 102）

Mac 上的 TVBox 兼容播放器，支持 Android TVBox 订阅配置。
基于 OKVideoMac 0.6.1 独立维护；保留 Yao Lin、贡献者及第三方版权与许可证。

- 产品分支：`main`，独立版本从 1.0.0 开始。
- 显示名称和交付目录为 MacBox；内部工程、可执行文件、Bundle ID、用户偏好和 Android 数据路径沿用旧标识，避免切断已有数据。
- 已换用原创盒形播放图标；原版和本修改版共享数据标识，不应同时作为独立安装运行。
- 包含此前原订阅解析、播放重试、设置布局、直播检测、播放防休眠、CoreAudio 及无损压缩运行环境改进。
- 构建产物采用本地 ad-hoc 签名；不宣称 Apple 公证或上游官方发布。
- 当前目标为 Apple Silicon Mac；未完成 Intel、iPhone 或 iPad 适配。

验证应记录 Release 打包、签名、安装主程序一致性、“关于”名称/版本和已有配置可见性。历史上游测试结果不替代当前验证。
