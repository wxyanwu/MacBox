# MacBox 1.1.0（Build 103）

Apple Silicon Mac 版本。基于 MacBox 1.0.0 更新，保留原有 Bundle ID、订阅、偏好、观看记录和已签名 Android Bridge APK。

## 更新内容

- 播放设置中以单行展示片头、片尾按钮和 `时:分:秒` 输入框。按钮取当前播放时间；输入框支持手工输入、上下箭头和键盘上下键按秒调整。
- 片头结束时间和片尾开始时间按剧保存，连续选集沿用；片尾只有在自然播放跨过设定位置时触发。
- 广告过滤独立开关，默认关闭。仅对完整 VOD HLS 播放列表中明确标出 `CUE-OUT`、`CUE-IN` 且时长一致的广告区间生效；普通片段和未标记片段不跳过。
- Android/DEX 搜索前检查 Bridge 是否被旧请求阻塞，超时后恢复本应用管理的 Bridge 进程；站点明确标记不可搜索时不计入搜索进度。

## 验证范围

- macOS Release 构建、签名和安装一致性以本次安装验证记录为准。
- 使用实际含广告标记的本地 HLS 视频，验证只识别广告区间，并确认广告前后的正常片段可以播放。
- 搜索结果受各订阅、站点、插件与网络状态影响；实测样本不能代表所有接口。

本项目为独立维护的 ad-hoc 签名版本，未声明 Apple 公证或上游官方发布。
