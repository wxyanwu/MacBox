# MacBox 1.1.1（Build 104）

Apple Silicon Mac 修复版，保留既有 Bundle ID、订阅、偏好、观看记录和已签名 Android Bridge APK。

## 更新内容

- 无需人工操作的 Android/DEX 播放解析最多等待 45 秒；超时后取消当前请求。若第三方插件不响应取消，则恢复本应用管理的 Bridge 进程，避免后续站点持续被锁住。已出现的授权界面继续保留交互等待。
- TVBox 线路需要真正开始播放才判定成功。对“已载入却直接跳到片尾”的线路给出明确错误，不再把它当成正常播完并连续跳集。失败信息带上线路和集数。
- 播放设置中片头、片尾时间文字垂直居中，保留单行布局及按秒输入操作。

## 验证范围

- 相关 XCTest 覆盖 Bridge 取消回执、恢复错误传递、时间输入和片尾误判规则。
- 实际片源验证以本次安装后的播放结果为准；不同站点和线路随上游状态变化。

本项目为独立维护的 ad-hoc 签名版本，未声明 Apple 公证或上游官方发布。
