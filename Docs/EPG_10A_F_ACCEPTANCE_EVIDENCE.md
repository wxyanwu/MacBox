# EPG 10A-F Release 验收证据

日期：2026-09-20。结论分开记录：Release 自动化和资源门禁 PASS；公开冻结 XMLTV
重放 PASS；TVBox/CatPaw/Xtream 私有真实源样本未提供，未验证。

## 冻结环境与口径

- 设备 `iMac21,1`，arm64，macOS 14.8.9 (23J631)，60 Hz，2× Retina。
- AppKit 资源门禁使用 Release binary SHA-256
  `e1274abd3445d51abc079ea2bdd719eb2c15bf6bdb085b21ef64b29df8da31a2`。
- 200K fixture SHA-256
  `948af49d8e587d55b25537af82aa414dc4bfb15d2e3f89d0c8c296eb31c21ded`。
- 每个 AppKit 场景运行三个独立进程。RSS/phys_footprint 每 10 ms 采样，覆盖生产
  loader、首次绘制、窄/宽/全屏尺寸、1×/2× layer、双轴滚动、日期跳转、generation
  替换、退出后 1 s 和 5 s settled。
- 帧间隔由 CVDisplayLink 提供主机时间戳，回调交付 App 主队列；没有使用普通 Timer
  冒充 FPS。P95 统一使用 nearest-rank `ceil(N × 0.95) - 1`。

## 来源验收范围

- 公开冻结 XMLTV 的 plain/gzip 都通过当前 Release Repository 重放：6 个频道、133 条
  programme，与 legacy oracle 一致。plain SHA-256
  `8508c19e3600d0f59cb34b90f8032d3cdb1d8d3dba116b8894bfc3006bd402f7`，gzip SHA-256
  `c804713c4b34ce19304960bebf39379679cb7d224cc17d968d1603d6fd503e7d`。
- 这是冻结样本重放，不代表当天实时网络可用性。
- 本次没有可用且已授权的 TVBox/CatPaw/Xtream 私有真实源 fixture 或账号，因此不宣称
  三生态真实源验收已通过。实现与自动化、公开来源、私有真实来源继续分开记录。

## 失败与修正记录

- 初始每节目 item 的超大 document/layer 路径产生不可接受的后备存；换成固定 viewport
  和虚拟偏移后重新从零运行三次。
- 初始 FPS 探针使用 Timer，不符合冻结协议；改为 CVDisplayLink 后废弃旧数据重跑。
- 1000 频道 fixture 最初超过生产 channel batch 上限；生成器改为每批最多 512，实际生产
  限制仍由 Store 强制。
- 30 分钟测试的短烟雾运行暴露重复加载同一媒体时宽高属性不重复通知，以及
  200K 刷新耗时可超过短 fixture。首次加载检查宽高，后续用新请求的
  `playing + position` 确认首帧；媒体余量冻结为每段额外 90 s。
