# OKVideoMac 0.6.1 screenshot manifest

These maintainer-supplied captures show the OKVideoMac 0.6.1 (Build 101)
interface in English and Simplified Chinese.

## Capture and content notes

- Capture date: 2026-09-09 to 2026-09-10.
- Appearance: native macOS light appearance.
- Content: fictional scenic demo titles and channels; no third-party catalogue,
  account, credential, private URL, log output or local filesystem path is shown.
- The Chinese live-player capture uses English fictional channel and provider
  names supplied by the demo data. Its application controls and status labels
  use the Simplified Chinese interface.
- The original 2048-pixel-wide PNG captures were proportionally resized to
  1600 pixels wide, converted to JPEG at quality 90 and stripped of metadata.
  No application content, control or window state was composited or redrawn.
